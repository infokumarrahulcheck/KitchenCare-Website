# KitchenCare Website

Static, mobile-friendly website for GitHub Pages / custom domain `kitchencare.life`.

## Publish on GitHub Pages
1. Create/open the GitHub repository for the website.
2. Upload **all files and the `assets` folder** from this package to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. In the Pages custom domain field, enter `kitchencare.life` and save.
5. In GoDaddy DNS, point the apex domain to GitHub Pages using GitHub's current A-record values, and add a `www` CNAME to `<your-github-username>.github.io`. Enable HTTPS after DNS verification.

## Before launch
- Confirm the Facebook share link opens the intended business page.
- Confirm service availability for each listed locality before accepting bookings.
- Google Business Profile verification and Search Console setup are separate from publishing this website.

## SEO note
The site includes page titles, descriptions, canonical URL, LocalBusiness structured data, sitemap, robots.txt, service descriptions and locality coverage. These help search engines understand the business but cannot guarantee a top result for every “near me” search. Local rankings also depend on Google Business Profile, reviews, proximity, competition and ongoing site authority.
