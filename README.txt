GitHub Pages deployment:
1. Extract this ZIP.
2. Upload the CONTENTS of the kitchencare-website folder to the root of your GitHub repository (index.html must be at repository root).
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Keep your existing GoDaddy DNS records connected to GitHub Pages.
5. Set kitchencare.life as the Custom domain in GitHub Pages and enable HTTPS when available.
6. Submit https://kitchencare.life/sitemap.xml in Google Search Console.
